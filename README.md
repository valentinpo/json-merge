# 🧩 JSON Merge

Простая утилита для объединения нескольких JSON-файлов в один.

## Как работает

Скрипт находит все `.json` файлы в текущей папке и объединяет их содержимое в массив `merged.json`. Файлы обрабатываются в алфавитном порядке для стабильного результата.

## Использование

```bash
python merge.py
```

Результат: `merged.json` в той же папке.

## Пример

В папке лежат файлы `X-U2.json`, `X-U3.json`, `X-W2.json` — скрипт объединит их содержимое в один список записей в `merged.json`.

В репозитории — пример с каталогами LED-контроллеров Onbon BX (X-U2…X-W4).
